## 1. 它是怎么工作的

Android 客户端是一个 **WebView 壳**，加载你自部署的 DeepTutor Web 端，然后在其上做两类增强：

| 层次 | 位置 | 作用 |
| ---- | ---- | ---- |
| 注入层 | `app/src/main/assets/shell.js` | 在页面加载前注入脚本：底部导航、补全提示可点、设置入口、下载拦截等 |
| 原生壳 | `app/src/main/java/dev/raaa/deeptutor/` | 文件选择、下载落盘、数学键盘面板、设置面板、沉浸模式、键盘让位 |

这样服务器地址换了、Web 升级了，壳里的增强仍然生效；只有 Web 的 DOM 结构大改时才需要同步调整注入层。

## 2. 首次启动与连接

第一次打开（或清除站点数据后）会进入连接页：

- 输入你部署的 Web 端地址，例如 `https://your-domain:port`
- 地址格式不合法会在输入框下方提示
- 使用明文 `http://` 地址时会提示不安全，可选择继续

![首次连接页](images/android-connect.png)

*图 1：首次启动的连接页（Notion 风格，浅色/深色自动跟随）*

连接成功后地址会保存在本机，后续启动直接进入。

## 3. 底部导航 Dock

手机端把网页顶部 44px 的汉堡条整条隐藏，改为底部常驻导航。

**导航项（6 个，顺序与侧边栏一致）**

| 位置 | 名称 | 跳转 |
| ---- | ---- | ---- |
| 1 | 首页 | `/chat`（新对话） |
| 2 | 学习 | `/learning` |
| 3 | 资源 | `/space` |
| 4 | 伙伴 | `/partners` |
| 5 | 个性化 | `/personalization` |
| 6 | 更多 | 打开原侧边抽屉 |

![底部导航 dock](images/android-dock.png)

*图 2：底部 6 项导航，当前页高亮*

**交互细节**

- 当前页面所属分类会高亮（会话详情页高亮「首页」）
- 点「更多」滑出原来的侧边抽屉（工作区、会话列表、设置、APP 设置都在里面），此时 dock 自动淡出，避免出现上下两层导航
- 弹出系统输入法或数学公式键盘时 dock 自动隐藏，收起后恢复，不额外挤占聊天可视区域
- 页面内容会整体上移，输入框不会被 dock 遮挡
- 平板/横屏（宽度 ≥ 768px）时 dock 自动隐藏，回到网页原生的桌面布局

![更多抽屉](images/android-drawer.png)

*图 3：点「更多」打开侧边抽屉*

## 4. 首页「继续上次对话」

网页端打开首页默认是新对话。手机端在空会话页额外提供一张卡片：

- 显示「继续上次对话」和最近访问的相对时间（如「2 小时前」「昨天」）
- 点击直接回到那次会话
- 只记录真正进入过的会话（URL 带会话 id），没有发过消息的空会话不会出现
- 记录保存在本机，7 天后失效；不上报服务器

![继续上次对话](images/android-continue.png)

*图 4：首页输入框下方的「继续上次对话」卡片*

## 5. 输入增强

### 5.1 点击「Tab 补全」

网页在输入框为空时会显示一行建议，并以「→ Tab 补全」提示按 Tab 接受。手机没有 Tab 键，因此这行文字**本身可点击**：

- 点击后自动把建议内容填入输入框，与按 Tab 键的效果一致
- 提示文字、位置、字号与网页完全一致，只是增加了可点击区域
- 建议内容不存在时（没有推荐问题），这行字本身不会出现

![Tab 补全](images/android-tab-complete.png)

*图 5：点击「→ Tab 补全」直接补全*

## 6. 数学公式键盘

页面边缘悬浮一个半透明的线性键盘图标，打开后是从底部升起的独立数学键盘面板（基于 MathLive）。

**面板能力**

- 布局分页：常用 / 123 / ∞≠∈ / αβγ
- 按键支持长按或上滑选择变体（如 1/2、平方、根号、希腊字母）
- 固定底部行：`+ − × ÷ =`、Shift、光标左右移动、退格、插入
- 「插入」默认按行内公式 `$...$` 写入聊天输入框，Shift 后按行间公式 `$$...$$` 写入
- 编辑区单行内容垂直居中，多行随内容自然增高

![数学键盘](images/android-math-keyboard.png)

*图 6：数学公式键盘与插入按钮*

**行为**

- 图标半透明、无底色，颜色跟随深浅色，不抢页面视觉
- 可自由拖动到任意位置，松手后记住该位置（A 点），重启 APP 仍保留
- 系统键盘弹出时，如果 A 点会被键盘盖住，图标自动被顶到键盘顶边之上；键盘收起后回到 A 点，任何情况下都不会遮挡输入框
- 拖动位移小于 8dp 视为点击，用于打开/收起键盘
- 键盘面板打开时图标自动隐藏
- 不需要时可在「APP 设置 → 数学公式键盘」关闭，关闭后图标隐藏

![数学键盘开关](images/android-math-toggle.png)

*图 7：设置中关闭数学键盘*

## 7. 添加内容（附件上传）

聊天输入框点「+」→「上传附件」后，弹出原生「添加内容」面板：

- **拍照 / 相册 / 文件** 三个入口并排，上图标下文字
- 配色与圆角与 Web 端一致，深色模式自动适配
- 「拍照」直接调用系统相机；「相册」调用系统照片选择器；「文件」调用系统文件选择器
- 选择了纯图片类型的上传入口时，会跳过面板直接进入相册

![添加内容](images/android-upload.png)

*图 8：添加内容三宫格（拍照 / 相册 / 文件）*

## 8. 文件下载

页面内产生的下载会交给原生处理，避免 WebView 无处保存：

- 普通 `http(s)` 链接：交给系统下载管理器，保存到系统「下载」目录，并有完成通知
- 页面生成的 `blob:` 文件（如导出、截图、生成的文档）：由注入层分块传给原生落盘，保存到系统「下载」目录
- 超过 32MB 的 blob 会被拒绝并提示保存失败

## 9. APP 设置

**入口**：侧边栏「通用工作区」下拉菜单 → 版本号下方 →「APP设置」

![APP 设置入口](images/android-settings-entry.png)

*图 9：侧边栏版本号下方的「APP设置」入口*

**面板内容**

| 分组 | 项目 | 说明 |
| ---- | ---- | ---- |
| 连接 | 服务器地址 | 保存地址并重新加载 |
| 外观与输入 | 沉浸模式 | 隐藏状态栏，从屏幕边缘下滑可临时调出 |
| 外观与输入 | 数学公式键盘 | 控制 Σ 悬浮按钮与数学键盘面板 |
| 高级 | 自定义样式目录 | 填包含 `custom.css` / `custom.js` 的目录地址，保存后立即拉取 |
| 高级 | 重新加载页面 / 清除站点数据 | 清除会同时退出登录回到连接页 |
| 关于 | 版本与当前地址 | 排查问题时提供给开发者 |

## 10. 外观与系统行为

- **深色模式**：跟随系统，App 设置面板、添加内容面板、数学键盘、底部导航统一换色
- **沉浸模式**：默认开启，隐藏状态栏；弹出设置面板或添加内容面板时也保持隐藏
- **应用图标**：白色底 adaptive icon，启动页同底色
- **返回键**：数学键盘打开时先收起键盘 → 页面可后退则后退 → 在首页再按一次退出
- **下拉刷新**：页面处于顶部时下拉可刷新当前页面
- **弹层让位**：点击带弹出层（模型选择、资源菜单等）的按钮时自动收起软键盘，避免遮挡

![深色模式](images/android-dark.png)

*图 11：深色模式下的底部导航与页面*

## 11. 高级：自定义注入层

面向自部署用户，可以在自己的服务器上放两个文件，让 APP 在页面加载时注入，改样式或打补丁都**不需要重装 APK**：

```
https://your-domain/custom-layer/
├── custom.css   # 追加到页面的样式
└── custom.js    # 页面加载后执行的脚本
```

在「APP 设置 → 自定义样式目录」填入该目录地址并保存即可。拉取失败会保留上一次的缓存。

## 12. 手机端专属功能速查表

| 功能 | 网页端 | Android 客户端 |
| ---- | ------ | -------------- |
| 一级导航 | 左上角汉堡 + 抽屉 | 底部 6 项 dock（更多 = 抽屉） |
| 打开首页 | 新对话 | 新对话 + 「继续上次对话」卡片 |
| Tab 补全 | 按键盘 Tab | 点击「→ Tab 补全」文字 |

| 设置入口 | 侧边栏设置 | 侧边栏「APP设置」（原生面板） |
| 沉浸/状态栏 | 无 | 沉浸模式开关 |
| 自定义样式 | 需改代码重新部署 | 远程 `custom.css` / `custom.js` |

## 14. 已知限制

- **依赖 Web 的 DOM 结构**：底部导航、继续上次对话、Tab 补全都基于页面现有的结构与类名；Web 端大改版后需要同步更新注入层。
- **宽屏自动退回网页布局**：宽度 ≥ 768px（平板、横屏）时不显示 dock，使用网页原生的侧边栏。
- **会话记录仅在本机**：卸载重装或清除站点数据后，「继续上次对话」记录会被清空。
- **自定义注入层需要可访问的静态目录**：目录需允许直接访问 `custom.css` / `custom.js`，不支持需要登录鉴权的地址。
